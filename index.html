現在の保存方式

業務データ：ローカル保存　現在は見積・案件・帳票・入金などの業務データをこのブラウザ内に保存します。Google Calendar との連動は API で行います。スマホ・PC間の業務データ共有は Firestore 接続後に有効になります。

Google Calendar API 連動

1. 「設定」→「Googleに接続」で Google アカウントを許可
2. 「Google日程を同期」で対象月を直接取得
3. 祝日・従業員の休みは自動除外
4. 見積・請求・領収の正式情報を保存すると、連携済みの元 Google Calendar イベントへ顧客名・正式金額・状態・システムリンクを反映
5. ICS取込は API が使えない場合の予備機能です

クラウド接続（段階導入）
