月輪合同会社 業務連動システム PWA試用版 v2

【手机端】
日程 / 見積履歴 / 帳票 / 保存帳票 の4項目だけを表示します。

【电脑端】
同じURLをPCで開くと、案件・売上入金・支出・銀行照合・月次など完全な后台メニューを表示します。

【保存帳票】
保存済みの見積書・請求書・領収書・小野田請求を一覧表示し、再度開く・PDF再ダウンロードができます。
同じ帳票は historyId で識別し、再ダウンロードしても同じ請求を二重売上登録しません。
領収書も sourceId で入金を識別し、同じ領収書の再ダウンロードによる重複入金を防ぎます。

※現在は試用版のため、スマホとPCのデータは各端末のブラウザ内に保存されます。
Firebase接続後に同じクラウドデータを共有します。
