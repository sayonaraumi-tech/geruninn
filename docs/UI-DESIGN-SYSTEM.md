# 月輪合同会社 業務システムの画面デザイン

## 色と文字

| 用途 | 値 |
| --- | --- |
| トップナビゲーション | `#171717` |
| ブランドアクセント・主ボタン | `#B5964C` |
| ページ背景 | `#F2F3F5` |
| 作業領域 | `#FFFFFF` |
| 本文 | `#202124` |
| 補助テキスト | `#666B73` |
| 区切り線 | `#E0E2E6` |

主ボタンはシャンパンゴールドの背景に濃色の文字を組み合わせる。フォントは Noto Sans JP を優先し、端末の日本語フォントにフォールバックする。外部フォントの取得は不要。

| 要素 | 標準サイズ | ウェイト |
| --- | --- | --- |
| ページ見出し | 22px | 700 |
| セクション見出し | 17px | 600 |
| 表の列見出し | 13px | 600 |
| 本文・表の本文 | 14px | 400 |
| 金額・ボタン | 14px | 600 |
| 補助テキスト | 12px | 400 |
| 状態ラベル | 12px | 600 |

サイズの基準はルート文字サイズ 16px。CSS では `rem` で指定する。余白は 4px 単位で、ラベルと入力欄の間は 4px、関連する操作の間は 8px、作業領域の基本パディングは 16px。白い作業領域の中は見出しと区切り線で整理し、カードを使う場合は入れ子を避ける。

## 共通クラス

| クラス | 用途 |
| --- | --- |
| `tsuki-ui` | 対象画面のコンテナ。デザイントークンを配下に提供する |
| `tsuki-shell` / `tsuki-topbar` / `tsuki-workspace` | ページ背景、トップナビゲーション、作業領域 |
| `tsuki-page-title` / `tsuki-section-title` / `tsuki-help` | ページ見出し、セクション見出し、補助テキスト |
| `tsuki-table-scroll` / `tsuki-table` | 横に広い表のスクロール領域と表。行高の基準は 40px。複数行の内容は折り返して行を伸ばす |
| `tsuki-amount` | 金額の列見出し・セルを右揃えにし、等幅数字を指定する。表示済みの通貨・符号・桁区切りを使用する |
| `tsuki-button` / `tsuki-button--primary` | 通常ボタン。主操作は修飾クラスを追加する。最低高 36px |
| `tsuki-input` | 入力欄、セレクト、テキストエリア。最低高 36px。エラー時は `aria-invalid="true"` とエラーメッセージを設定する |
| `tsuki-status` | 中立の状態ラベル。成功・注意・エラーには `tsuki-status--success`、`tsuki-status--warning`、`tsuki-status--danger` を追加する |

入力欄には対応する `label` を付ける。ボタンは既存の操作と無効状態を引き継ぎ、キーボードフォーカスを表示する。状態ラベルには「入金済」「要確認」などの既存の状態名を使い、色と文字の両方で示す。横スクロールが必要な表にはキーボードでも操作できるよう、スクロール領域に `tabindex="0"` と分かりやすいラベルを設定する。

## 導入手順と対象

画面移行時に、[デザイントークン](../css/design-tokens.css)、[共通 CSS](../css/ui-foundation.css) の順で読み込む。対象の画面領域に `tsuki-ui` を付け、その子要素に必要な共通クラスを追加する。

```html
<div class="tsuki-ui">
  <section class="tsuki-workspace" aria-labelledby="sales-title">
    <h1 id="sales-title" class="tsuki-page-title">売上・入金</h1>
    <table class="tsuki-table">
      <thead><tr><th scope="col">摘要</th><th scope="col" class="tsuki-amount">金額</th></tr></thead>
      <tbody><tr><td>クロス工事</td><td class="tsuki-amount">¥85,000</td></tr></tbody>
    </table>
  </section>
</div>
```

この変更では CSS と利用規約を追加する。既存画面への読み込みとクラスの追加は画面単位の移行で行う。

- **PC** はホーム、日程、見積履歴、帳票、保存帳票、売上・入金、支出・現金、銀行照合、設定の全9画面。
- **スマートフォン** は日程、帳票、帳票履歴（現行ナビの「保存帳票」）の3画面。見積履歴など、ほかの画面のスマートフォン向けデザインとナビゲーションの公開範囲は現行仕様に従う。
- **帳票** では画面の操作部だけが対象。帳票プレビュー、PDF に渡す DOM、印刷テンプレートを `tsuki-ui` の適用領域から外す。両 CSS は `screen` メディア専用。画面表示から生成する PDF も、帳票 DOM を画面用スタイルから独立させて保護する。
- **業務処理** では既存のイベント、権限、Firestore の保存形式と履歴、帳票の変換・出力、金額の算出と表示内容を引き継ぐ。適用するのは表示クラスのみ。
