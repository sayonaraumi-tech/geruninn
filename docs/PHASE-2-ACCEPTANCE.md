- 独立的屏幕样式、页面/主题适配器、月历计算模块和只读统计适配器；复用现有业务服务、同步队列、数据库字段与权限。

- 将只弹出提示的手动销售按钮改为进入正式請求书登记流程，不恢复绕过正式账票的本地写入。
- 调整原浏览器测试服务的 CSS 响应类型，并把旧黑金样式的固定断言改为 v13 基准；保留财务和权限断言。新增真实模拟器日程/主题/九页验收和控件清单。
