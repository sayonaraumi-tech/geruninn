# 税理士確認用資料（第四段階）

管理者でクラウドにログインし、月次・決算の年度開始年を選びます。年度は10月1日から翌年9月30日です。月次・年度・確認事項・エクスポートを切り替え、11種類の資料CSVと監査CSVを個別に保存できます。CSVはUTF-8 BOM付きです。

売上は有効な売上レコードをIDで一度だけ計上し、関連帳票が無効・取消・重複・訂正済なら除きます。正式訂正は従来の同一saleIdを維持します。期末未収は期末までの売上から期末までの確認済入金を差し引き、過年度未収も含みます。月次合計を積み上げて年度を計算します。現金出納帳は年度前の繰越を含めた残高を表示します。銀行支出は支出レコードの銀行等支払分で、現金・月締を除きます。仕入先CSVは月別と年度の前払・請求・支払・調整および期首期末残高です。

確認事項は自動修正しません。日付欠落・ID重複・有効請求書の重複は全データを確認します。資料は税務申告や税額の確定ではなく、税理士による確認が必要です。

バックアップはクラウドの全collection同期完了後、未同期キューが空の場合のみ保存します。companyId、schemaVersion 4、exportedAtと主要業務collectionを含み、秘密情報のキーを再帰的に除きます。operations（再送防止用）は含めません。バックアップの検証はcompanyId・schema・collection・ID・revision・秘密情報を確認し、件数をプレビューします。実際の復元やデータの上書きは行いません。バックアップには個人・取引情報があるため安全に保管してください。

既存のFirestoreルールによるadmin限定銀行・会計・監査読み取りを継続使用します。staffは年度エクスポート、バックアップ、検証、監査の入口を利用できません。新しいFirestoreルールや索引の追加は不要です。
