# 月輪合同会社 原记账系统 — 电脑端 9 页功能审计清单

基线分支：`refactor/internal-structure-20261115`  
审计日期：2026-11-15  
用途：供后续 UI 重新设计（Grok Build）时完整保留现有功能。

## 全局约束
- 保留全部现有业务功能、历史数据兼容、PDF 模板与自动编号。
- 财务计算结果（売上・入金・未収・现金・银行照合）不得改变。
- 請求書「値引き」为新增功能，需在重新设计时保留。
- 不得修改正式 Firebase 数据。

## 1. HOME（pageDashboard）
**数据来源**：Firestore `sales` / `payments` / `expenses` 汇总；本地 `bizState`。  
**主要字段/控件**：
- 期间选择（月次 / 年度 / 自定义）
- KPI 卡片：売上、入金、未収、支出
- 年度切换、決算・エクスポート入口
- 月次/年度卖上一览 CSV、全数据备份
**操作流程**：切换期间 → 刷新 KPI → 导出 CSV / 备份。  
**业务联动**：与売上・入金・支出台账实时同步。  
**实现状态**：已上线，单元测试覆盖期间计算。

## 2. 日程（pageCalendar）
**数据来源**：Google Calendar 同步 + 本地 `calendarLinks`。  
**主要字段/控件**：
- 日历视图、事件列表
- 与帳票关联（见积/请求/领收）
- 小野田月次再生成入口
**操作流程**：同步 Google → 选择事件 → 生成或关联帳票。  
**业务联动**：事件可转换为見積書/請求書；小野田专用帳票从日程汇总。  
**实现状态**：已上线，浏览器测试覆盖同步与去重。

## 3. 見積履歴（pageEstimates）
**数据来源**：`documents`（docType=estimate）+ 本地历史。  
**主要字段/控件**：
- 见积列表（编号、日期、客户、金额）
- 搜索、排序、状态切换
- 转换为請求書 / 領収書
**操作流程**：查看历史 → 选择 → 转换或重新编辑。  
**业务联动**：转换时生成新帳票并关联原见积；不重复生成売上。  
**实现状态**：已上线。

## 4. 帳票（pageChohyo）
**数据来源**：表单状态 + `documents` 快照。  
**主要字段/控件**：
- 类型切换：請求書 / 見積書 / 領収書 / 小野田請求
- 客户、日期、编号、明细、出差费、备考
- **請求書値引き**：默认隐藏，「値引きを追加する」展开；税前扣除，重算消费税与合计
- 预览 / PDF 下载 / 保存
**操作流程**：填写 → 预览 → 下载 PDF（触发保存与财务联动）。  
**业务联动**：
- 請求書 → 売上 → 入金 → 未収
- 现金領収書 → 已确认入金 + 现金账
- 小野田专用帳票保留原版式
**实现状态**：已上线；値引き为本次新增，需在 UI 重设计中保留。

## 5. 保存帳票（pageSavedDocs）
**数据来源**：本地 `tsukinowa_chohyo_confirmed_history_v1` + 云端 `documents`。  
**主要字段/控件**：
- 已保存帳票列表
- 重新打开 / 再次下载（不修改财务数据）
- 删除（需确认关联影响）
**操作流程**：选择已保存记录 → 重新编辑或仅下载。  
**业务联动**：再次下载不重复入账；编辑后重新保存更新快照。  
**实现状态**：已上线。

## 6. 売上・入金（pageSales）
**数据来源**：`sales` + `payments`。  
**主要字段/控件**：
- 期间筛选、排序
- 台账表格（売上日、客户、请求额、入金済、未収、状态）
- CSV 输出
- 入金登记
**操作流程**：筛选 → 查看未収 → 登记入金 → 更新余额。  
**业务联动**：与銀行照合、现金账、未収余额实时一致。  
**实现状态**：已上线，浏览器测试覆盖期间与 CSV。

## 7. 支出・現金（pageExpenses）
**数据来源**：`expenses` + 现金出纳。  
**主要字段/控件**：
- 支出列表、科目、取引先
- 现金调整
- CSV 输出
**操作流程**：登记支出 → 立即反映支払済（现金）或待照合（银行）。  
**业务联动**：现金支出扣现金账；银行支出进入照合队列。  
**实现状态**：已上线。

## 8. 銀行照合（pageBank）
**数据来源**：银行 CSV 导入 + `bankTransactions`。  
**主要字段/控件**：
- CSV 导入、去重
- 入金/支出照合
- 平台结算、代表者立替排除
**操作流程**：导入 CSV → 匹配入金/支出 → 确认。  
**业务联动**：确认入金不重复创建売上；平台净额与手续费正确处理。  
**实现状态**：已上线。

## 9. 設定（pageSettings）
**数据来源**：本地配置 + Firebase Auth。  
**主要字段/控件**：
- 云端登录/登出
- 数据备份/恢复
- 显示设置
**操作流程**：登录 → 同步 → 备份。  
**业务联动**：多设备同步；本地数据在云端失败时保留。  
**实现状态**：已上线。

## PDF 约束（所有帳票）
- 保留原版式、Logo、印章、自动编号、税额取整规则。
- 値引き仅在請求書且金额 > 0 时显示为「値引き −N円」。
- 历史帳票再次下载不得改变财务数据。
